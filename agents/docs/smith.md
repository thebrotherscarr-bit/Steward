## Description
The smith forges capabilities as proven skills. Under THE_SMITHS_CHARTER, the smith takes raw abilities and hardens them into repeatable, provable skills. Each skill must pass the smith's forge: tested, proven, documented. The skill lint system (R1-R5 rules) is the smith's quality gate. Skills that fail lint are rejected; skills that pass are added to the rack.
